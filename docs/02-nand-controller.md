# 02 · NAND 控制器（NFI）与读写擦

## 1. 硬件

| 项 | 值 |
|---|---|
| 闪存 | **UNIM（至讯创新）UM19A8LISW** |
| 类型 | SPI-NAND / **SLC** / 32 MB（256 Mb）/ 1.8 V / WSON8 |
| 页 | 2048 B + 备用区 78 B |
| 块 | 64 页 = 128 KB |
| 总块数 | 256（2 个平面，每平面 128 块） |
| 扇区 | 512 B（每页 4 个） |
| 控制器 | 展锐 NFI，基址 **`0x21A00000`** |

### 1.1 芯片命令（SPI-NAND 标准）

| 命令 | 用途 |
|---|---|
| `0x9F` | Read ID |
| `0xFF` | Reset |
| `0x0F` / `0x1F` | Get / Set Feature（配置寄存器 `0xB0`、状态 `0xC0`、`0xA0`） |
| `0x13` | Page Read（从阵列读到 cache） |
| `0x6B` | Quad Read From Cache |
| `0x06` | Write Enable |
| `0x10` | **Program Execute**（写页——注意不是"读页"） |
| `0xD8` | Block Erase |
| `0x32` / `0x34` | Quad Program Load（主区 / 主区+备用区） |

### 1.2 NFI 寄存器（`0x21A00000` 起）

| 偏移 | 名称 | 说明 |
|---|---|---|
| `0x000` | START | 启动事务。**写 `1`**（不是 burst 值） |
| `0x004` | CFG | 事务类型：短命令 `0x02` / 擦除 `0x8102` / 读页 `0x78` / 写页 `0x8178` |
| `0x008` | LEN | **本次传输字节数**（见 §2 第 1 条） |
| `0x010` | STAT | 状态：bit24 完成、bit27 出错；写 `0xF00` 清标志 |
| `0x014`/`0x018` | TIMING | `0x3A493146` / `0x192A0000` |
| `0x0F8` | — | 恒 `0x3A`（读路径用 `0x02`/`0x403A` 变体） |
| `0x0B0`/`0x0B4` | ECC 配置 | `0x1004` |
| `0x0EC` | — | `0x00040002` |
| `0x19C` | DATA | 数据出口（读回一个字） |
| `0x200`/`0x204` | 描述符 A | 标志 / 地址 |
| `0x208`/`0x20C` | 描述符 B | 备用区（标志 / 地址） |
| `0x210`/`0x214` | 描述符 C | 方向 / 地址 |
| `0x220` | FIFO | 命令 FIFO（见 §1.3） |

### 1.3 FIFO 编码

| 值 | 含义 |
|---|---|
| `0x00`–`0xFF` | 发 1 字节 |
| `0x1000` | 收 1 字节 |
| `0x2000+N` / `0x3000+N` | 描述符 A 发 / 收 N 字节 |
| `0x4000+N` / `0x5000+N` | 描述符 B 发 / 收 N 字节 |
| `0x6000` | 哑字节 |
| `0xE000` | 结束 |
| `0xE001` | 结束并取结果 |
| `0xE201` | 结束并传输 |
| `0xF000` | 执行 |

## 2. ★ 四个致命参数（写错就永久卡死）

这四条是本项目最贵的经验，任何一个写错，症状都是"看不出报错，但就是不工作"。

| # | 规则 | 写错的症状 |
|---|---|---|
| 1 | **`NFI[0x008]` 必须 = 本次实际传输字节数**（512 → `0x31FF`），**不是页大小** | 传 `0x37FF` ⇒ 永久挂在 `START = 0x40000000` |
| 2 | **`NFI[0x000]` 启动值必须是 `1`**，不是 burst `0x2800` | 事务不启动 |
| 3 | **整页 2048 不能一次搬完**，必须 **4 × 512 扇区**循环 | 数据错 / 卡死 |
| 4 | **每个扇区必须 LOAD + EXECUTE**，不能攒着 | cache 在事务之间被清成 `0xFF` |

补充事实：

- `NFI[0x000]` 回读 bit4 是完成标志：`0x40000010` 正常，`0x40000000` 卡死；
- `NFI[0x0F8]` 恒 `0x3A`；方向位在 `NFI[0x004]` 的 bit15；
- `NFI[0x004]` 高字节 = (扇区数 − 1)。

> **关于"单事务多拍"**：我们试过用 cfg 高字节塞扇区数、`NFI[8]` 塞整页长度、
> 描述符 `0x2800/0x2E00` —— **全部超时**。参考固件同样是"每扇区一个事务"，
> 所以这不是遗留问题，是这颗控制器的实际能力边界。

## 3. 初始化

顺序固定：**时钟 → 复位 → PHY → NFI → 芯片复位**。

```
① 时钟门控   0x21500000 +0x60 = 3 ; +0x24 |= 2
② NFI 复位   0x20E00000
③ PHY        0x402E0000 |= 0x100000 ; 0x402E00B0 |= 0x1000 ; 0x402A0024 |= 0x1000
             再把 0x402A00xx / 0x402A05xx 一批寄存器按固定值写好（见 phy_init）
④ NFI 基线   0x014/0x018/0x034/0x038/0x0B0/0x0B4 …
⑤ 芯片复位   0xFF → 0xE000 → 0x0F 0xC0 → 0x1000 → 0xE001 → 0xF000
             然后 NFI[0x000]=1 + nf_wait
```

⚠️ **外设初始化阶段只写不读**：`0x21500060` / `0x20E00004` 这些在使能之前读会挂总线。

`nand_ensure()` 用 `g_nand_ready` 做一次性保护，只有第一次调用会真正初始化。

## 4. 读一页

```
① 发 PAGE READ (0x13)
   nf_one(cfg=0x02, psiz=0x3000, row, col=0, cmdset=21)
② 轮询状态，最多 400 次，每次 nf_delay(2000)
   实测：**1 轮就成功**（tR 只有几十微秒）
③ 取数据
   4 个扇区 × (QuadReadFromCache 0x6B → 描述符 A 收 512 字节 → cache_inv)
```

`flash_read_page(row)` 读的是**整页 2048 B**，落在 `DBUF`。
备用区用 `cmdset 82` / `cmdset 75` 单独读（`0xFE` 命令可回传 OOB）。

## 5. 写一页（`cmdset 84`，本项目的核心路径）

```
① 主机（或固件自己）准备好 2048 B 主区数据在 DBUF
② 若主机没给 OOB：ecc_fill_oob(DBUF → OBUF)     ← 78 字节
③ 每 512 字节扇区循环 4 次：
     LOAD   (0x32 / 0x34)       把扇区推进芯片 cache
     设 NFI[0x008] = 该扇区实际字节数 | 0x3000 | (OOB-1)<<16
     EXECUTE                    触发写页
     状态轮询（页 0/1 额外慢路径）
④ 返回
```

`g_wr_mode` 控制等待策略：

| mode | 行为 | 速度 |
|---|---|---|
| 0 | 每个扇区固定 `nf_delay(20000)` + 轮询 | 慢（35 ms/页） |
| **20（默认）** | 页 ≥2：零延时 + 只在需要时轮询；页 0/1 保留慢路径 | **3.58 ms/页** |

> mode 20 是"验证过的快路径"：整块 64 页写入 0 错。
> 砍掉轮询换纯延时是**错的**——`tPROG` 会超过 1 ms，延时替代轮询会写坏页。

## 6. 擦一块

```
nf_one(cfg=0x8102, cmdset=40/41/42, row=块首行)
```

命令序列：`0x06`(WREN) → `0xD8`(BlockErase) → 轮询 `0xC0` 状态。
擦除是**整块 64 页**，一次擦 128 KB。

## 7. 页序：块内页 0/1 必须最后写

写第 2…63 页会**扰动块首两页**（program disturb），所以：

```
写块：先把页 0/1 扣在 g_hold[2]
      页 2…63 正常写
      块写完（或 END_DATA 收尾）→ flush_hold() 补写
      ★ 补写顺序是 1 → 0（页 1 的编程会扰动页 0，所以页 0 最后）
```

这条是实测结论：顺序反过来，页 0 会出现整字节错误。

## 8. 速度实测量级

| 操作 | 耗时 |
|---|---|
| 写一页（mode 20，cache 开） | **3.58 ms** |
| 读一页 | ~1.2 ms |
| 写 19.24 MB（三分区） | 35.3 s |
| 读 19.24 MB | 11.8 s |

> 参考固件的 8.96 MB 约 3.6 s ≈ 0.8 ms/页——差距主要在每页事务数与总线效率，
> 属于未完成优化项，见 `docs/06-limitations.md`。
